# 7Network hero animation art

Six isolated transparent 3D interface planes for a future scroll-driven hero animation.

- `layers/01-crm-pipeline-sales.png`: pipeline and sales dashboard anchor.
- `layers/02-whatsapp-campaigns.png`: WhatsApp campaign delivery.
- `layers/03-ai-chatbot.png`: AI bot workflow.
- `layers/04-follow-up-automation.png`: tasks and reminders.
- `layers/05-unified-inbox.png`: shared inbox conversations.
- `layers/06-invoicing-payments.png`: invoice and payment state.
- matching `*-aligned.png` files are full-canvas transparent sprites with the original sheet coordinates preserved.
- `scene-source.png` is the generated 3-column by 2-row source sheet; `preview.jpg` shows the separated layers together on navy.
- `layers.json` provides canvas and per-layer position metadata.

These are illustrative graphics, not live product screens. The artwork is already rendered in isometric perspective, so use subtle rotations/parallax when placing it on 3D planes.
